一、怎么打开使用
────────────────
· 电脑：双击「index.html」文件，用 Chrome 或 Edge 打开即可。
· 安卓手机：把 index.html 传到手机（微信/QQ/USB 都行），
  用 Chrome 打开。
· iPhone：建议请开发者把本文件免费部署到网上（如 GitHub Pages），
  然后用 Safari 打开网址，点「分享 → 添加到主屏幕」，
  之后就能像普通 App 一样点图标进入，
  主屏幕会显示你自定义的App图标（不再是默认的"可"字）。

二、⚠️ 最重要的事：数据备份（请先读这条）
────────────────
你的所有数据（空间/待办/日记/图片）都存在「当前浏览器的本地存储」里，
不会上传到任何服务器。这意味着：

  1. 换浏览器 = 数据不在了（需要在旧浏览器导出、新浏览器导入）
  2. 清除浏览器数据 = 数据不在了
  3. 换电脑 = 数据不在了

所以请养成习惯：每周点一次「设置 → 导出备份」，
把下载的 JSON 文件保存好（可以存到网盘）。
万一数据丢失，在「设置 → 导入备份」选那个文件就能完整恢复（含图片）。

三、进入游戏世界：纯净首页与手势
────────────────
打开软件，最先看到的是你的看板娘和背景（默认小可爱占位角色，
以后可在设置里换上你自己的图），界面干干净净，一切由手势呼出：

【单击看板娘】
  → 她会对你说一句话（气泡在立绘右上）、跳一跳或软软一挤，冒出小爱心
  → 同时浮现「角色养成」入口按钮（浅粉玻璃胶囊，点它=养成面板：换形象等）
    和「大小/位置调节条」：−/＋ 调大小（0.6~1.6倍）、点「还原」恢复默认；
    位置不用按钮——调节条出现期间，按住立绘直接拖到哪里就是哪里
    （立绘会显示虚线框提示可拖动）；调整会记住，下次打开还在
  → 提醒气泡（最优先待办/闹钟/额度用完）同样在立绘右上显示

【双击】屏幕空白处或看板娘
  → 呼出/收回「节律表操控台」（底部玻璃面板）
  → 单击互动与双击互不冲突：先单击等一等才会互动，双击则直接开面板

【双击后紧接着左滑】
  → 操控台切到「空间」页：横向空间卡片 + 底部投放区

【长按约0.7秒 + 朝四个方向滑动】
  按住不动约0.7秒：按压处出现一个由浅渐实的圆圈+四个方向箭头，
  表示长按成功、可以滑动了；朝某方向滑动时该方向箭头会放大
  （滑出一点距离即可，松手跳转）：
  → 上 = 节律表
  → 下 = 待办
  → 左 = 空间列表
  → 右 = 我们的共识

顶部：日期（点它=我们的共识·今天）、日期下方的大时间（点它=闹钟）。
角落：最优先待办（实时倒计时，点它=待办页）、
剩余节律额度、正在递归的空间（点它=节律表）。

四、节律表操控台（双击呼出）
────────────────
两个页签：
【自流转】今天的自流转时段卡，每张卡：
  · 状态小表情：😴未开始 / 🐱进行中 / ✅已结束 / ⚠️未生效或额度不足
  · 头顶一对猫耳朵：＋10分钟 / －10分钟，改这张卡自己的时间段
    （最短10分钟，最晚到23:50，不跨天）
  · 进行中时卡片右上、左下各有一个小三角：
     按住右上三角往左拉 = 提前结束（拖得越远结束得越早，松手生效）
     按住左下三角拉开 = 停止本段并跳过今天（猫耳旁 ↻ 可恢复）
     没拉够就松手 = 什么都不会发生（还原）
  · ✎ = 编辑日程，＋ = 添加自流转日程

【空间】横向卡片列表 + 底部虚线「投放区」：
  · 按住空间卡片拖到投放区 = 开始这个空间的可能性递归
  · 递归进行中，投放区显示「正在递归：XX空间」，点一下 = 停止
  · ＋新空间 = 新建空间

面板右上 ⚙ = 设置；✕ = 收起面板。

五、我们的共识（长按右滑，或点角落日期）
────────────────
「我们的共识页，与日历合并」——点月历任意一天，看这一天：
  · 干了什么：节律消耗进度、24小时递归时间带、自流转日程执行情况、
    当日待办完成情况、时间轴日记（共识页专属，可补记/编辑/删除）
  · 积累了什么：每个空间的递归分钟数、可能性确定条数、新增迭代笔记
（历史日可补记当天日记，待办按「当日X截止」口径）

六、四大板块快速上手
────────────────
【待办】（长按下滑）点「新建待办」记下要做的事：
  · 单次：指定日期时间（如办签证 9月21日12:00）
  · 每日：每天固定时刻（如背单词 每天21:00）
  · 每周：勾选星期几（如接妹妹放学 周一~周五20:00）
  · 备忘：无期限的随手记
  卡片会倒计时：蓝色→剩4小时变黄→剩30分钟变红（每张卡可单独调）。
  点一下变绿出现红色问号（10秒内再点一次才完成，防误触），
  再点变成灰色带绿勾=完成；点灰色卡片可恢复。
  在共识页/节律表翻到过去的某一天时，也可以点待办卡片补记
  那一天的完成情况（显示"当日15:00截止"，完成后当天生效，
  不影响今天）。

【空间】（长按左滑）你的兴趣像书一样独立成册。新建空间（学日语/画画/…）后：
  · 可能性确定：每天可以写很多条（情绪😊、标签、笔记、图片），
    每条还能「收藏」进一个确定性迭代里长期留存
  · 日历：按天回溯，哪天有记录一目了然
  · 确定性迭代：分类小空间（默认4个：做过的事/掌握的知识/将做的事/将要掌握的知识），像图库歌单一样收纳长期笔记
  · 待办：属于这个空间的待办

【节律表】（长按上滑）一天24小时的时间管理：
  · 节律递归时间：每天的时间额度，点统计卡右上角的
    「今日额度 ✎」可以为当天单独设定（30分钟~24小时），
    其他天沿用设置里的默认值
  · 可能性递归：拖空间卡到操控台投放区（或在本页点「可能性递归」）
    开始消耗额度计时，再点停止；消耗的时间会等量记到那个空间头上
  · 自流转：课程表式日程，到点自动开始用指定空间消耗额度
    （支持复制到未来几天、每周重复）
  · 时间轴日记：已搬到「我们的共识」页（长按右滑进入），随时记录想法、
    补记过去某一天

【回看历史】共识页和节律表顶部都有日期条：◀ 日期 ▶ 一天天翻，
也可以点 📅 直接打开日历选择跳到任意一天（蓝色格子=有记录的日子），
查看那天的待办完成情况、节律消耗、时间带和日记。

【每日情绪】有三种、互不影响：
  · 共识页/节律表共享的「当日心情」：日期条上的 🙂 按钮，记录这一天
    总体的情绪和标签（与各空间无关）
  · 每个空间的每日情绪：空间「可能性确定」页顶部的一排表情，
    只属于这个空间，日历上显示的就是它（不会沿用记录里的表情）
  · 每条可能性确定自己的情绪：写在记录里

【自定义背景】设置 → 背景外观：
  · 选择一张图片作为纯净首页的背景（默认是天空渐变），
    可调透明度和模糊度，看板娘与背景分开显示
  · 看板娘立绘：把图片命名为「看板娘.png」放在 index.html 同文件夹即可；
    也可以在「单击看板娘 → 🎀 角色养成」里切换：
    看板娘.png / 内置占位小可爱 / 上传自定义立绘（透明PNG最佳）

【动画强度】设置 → 动画强度：完整 / 轻度（默认）/ 关闭。

【电脑桌面】窗口较宽时，纯净首页右下角会出现「今日递归时间带」
面板：正在递归时显示空间名与实时计时，下方是今天24小时的
专注色带（红线=当前时刻）。

七、小词典
────────────────
· 可能性空间   = 你的一个兴趣（学日语、拍视频……）
· 可能性确定   = 在空间里做记录（情绪/标签/笔记/图片）
· 可能性递归   = 用空间消耗节律递归时间（专注计时）
· 节律递归时间 = 每天的时间额度（被递归消耗）
· 可能性递归时间 = 已消耗的时间（等量记到空间名下）
· 确定性迭代   = 空间内的分类小空间（收纳长期笔记）
· 自流转       = 课程表式自动递归
· 节律表操控台 = 双击呼出的时段卡操作面板

八、常见问题
────────────────
· 时间怎么算的？
  递归计时按真实时间走：开始递归后就算关掉页面，时间也照算
  （关超过2小时会自动结束，防止忘记停止）。
  自流转日程即使关着页面也会按课程表补算。

· 存储满了怎么办？
  软件使用浏览器的大容量存储（通常几百MB，设置页会显示可用容量），
  图片还会自动压缩（最长边1000像素），正常使用很难存满。
  万一提示空间不足，导出备份后删除一些旧图片即可。
  个别旧浏览器会退回兼容模式（约5MB），建议用最新版浏览器打开。

· 更新后第一次打开：数据会自动从旧的小仓库搬进新的大仓库（几秒钟完成），
  之后请一直用新版页面；旧版页面看不到新仓库里的数据。

· 误删了怎么办？
  空间删除其实是「归档」，历史数据都保留，导出备份里也有。

· 想先体验一下？
  打开后双击屏幕 → 面板右上 ⚙ 设置 →「生成示例数据」，
  会创建学日语、练画画、软件开发三个空间和几条示例待办，随便点不心疼；
  体验完可在设置里「清空全部数据」（会先帮你自动下载备份）。
