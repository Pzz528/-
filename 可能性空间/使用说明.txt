一、怎么打开使用
────────────────
· 电脑：双击「index.html」文件，用 Chrome 或 Edge 打开即可。
· 安卓手机：把 index.html 传到手机（微信/QQ/USB 都行），
  用 Chrome 打开。
· iPhone：建议请开发者把本文件免费部署到网上（如 GitHub Pages），
  然后用 Safari 打开网址，点「分享 → 添加到主屏幕」，
  之后就能像普通 App 一样点图标进入，
  主屏幕会显示你自定义的App图标（不再是默认的"可"字）。
  ⚠️ v1.5 起，部署时要和 index.html 一起上传一个新的小文件
     「sw.js」（详见第十节「她的通知」）——没有它，软件照样能用，
     只是她走不出软件、没法给你发系统通知。

二、⚠️ 最重要的事：数据备份（请先读这条）
────────────────
你的所有数据（空间/待办/日记/图片）都存在「当前浏览器的本地存储」里，
不会上传到任何服务器。这意味着：

  1. 换浏览器 = 数据不在了（需要在旧浏览器导出、新浏览器导入）
  2. 清除浏览器数据 = 数据不在了
  3. 换电脑 = 数据不在了

所以请养成习惯：每周点一次「设置 → 导出备份」，
把下载的 JSON 文件保存好（可以存到网盘）。
万一数据丢失，在「设置 → 导入备份」选那个文件就能完整恢复（含图片）。

三、进入游戏世界：纯净首页与手势
────────────────
打开软件，最先看到的是你的看板娘和背景（默认小可爱占位角色，
以后可在设置里换上你自己的图），界面干干净净，一切由手势呼出：

【单击看板娘】
  → 她会对你说一句话（气泡在立绘右上）、跳一跳或软软一挤，冒出小爱心
  → 同时浮出「⭐」入口：一个白色圆圈里包着一颗黑星，浮在她身上。
    按住这颗星 0.5 秒 = 进入她的空间（详见第八节）；
    它 6 秒后自己隐去，再点一下她就会重新浮现。
  → 你不点她的时候，她也会自己找你说话（打招呼、催待办、睡前总结、
    惦记你很久没做的事）——详见第九节。

【按住看板娘单指拖动】直接移动她的位置（拖到哪里就停在哪里，自动保存）
【双指捏合】缩放她的大小（0.6~1.6 倍），默认展示宽度最高 100%（可占满整屏）
  → 提示：提醒气泡（最优先待办/闹钟/额度用完）在立绘右上、日期时间下方显示

【双击】屏幕空白处或看板娘
  → 呼出/收回「节律表操控台」（底部玻璃面板）
  → 单击互动与双击互不冲突：先单击等一等才会互动，双击则直接开面板

【双击后紧接着左滑】
  → 操控台切到「空间」页：横向空间卡片 + 底部投放区

【长按约0.7秒 + 朝四个方向拖动】——像把那个页面从屏幕边缘「拉出来」
  按住不动约0.7秒：按压处出现一个由浅渐实的圆圈，屏幕四条边各浮出一个
  页面图标（图标旁的箭头指向画面内=要往哪个方向拉），表示可以拉了：
  → 向左拉：把右边的「我们的共识」拉出来（暖黄色半圆从右侧鼓出来）
  → 向右拉：把左边的「空间」拉出来（深蓝色半圆从左侧鼓出来）
  → 向上拉：把下面的「待办」拉出来（浅绿色半圆从下方鼓出来）
  → 向下拉：把上面的「节律表」拉出来（红色半圆从上方鼓出来）
  半圆形色块会随拉的距离越来越大（拉得越远越大）；拉过一半后图标再放大一圈、
  名称反白，提示“松手即可进入”。松手 → 先闪一下同颜色的加载页（约0.5秒）
  → 进入那个页面；没拉够就松手 = 弹回原位，什么都不会发生。

顶部：日期（点它=我们的共识·今天）、日期下方的大时间（点它=闹钟）。
  觉得日期/时间太小或太大？「设置 → 纯净首页 · 看板娘」里有两条字号滑杆，
  拖动即可自定义（默认日期15px、时间36px，可一键还原）。
角落：最优先待办（实时倒计时，点它=待办页）、
剩余节律额度、正在递归的空间（点它=节律表）。

四、节律表操控台（双击呼出）
────────────────
两个页签：
【自流转】今天的自流转时段卡，每张卡：
  · 状态小表情：😴未开始 / 🐱进行中 / ✅已结束 / ⚠️未生效或额度不足
  · 头顶一对猫耳朵：＋10分钟 / －10分钟，改这张卡自己的时间段
    （最短10分钟，最晚到23:50，不跨天；只在「进行中/时段内」的卡上出现，
    已结束与未开始的卡没有猫耳）
  · 进行中时卡片右上、左下各有一个小三角：
     按住右上三角往左拉 = 提前结束（拖得越远结束得越早，松手生效）
     按住左下三角拉开 = 停止本段并跳过今天（猫耳旁 ↻ 可恢复）
     没拉够就松手 = 什么都不会发生（还原）
  · ✎ = 编辑日程，＋ = 添加自流转日程

【空间】横向卡片列表 + 底部虚线「投放区」：
  · 按住空间卡片拖到投放区 = 开始这个空间的可能性递归
  · 递归进行中，投放区显示「正在递归：XX空间」，点一下 = 停止
  · ＋新空间 = 新建空间

面板右上 ⚙ = 设置；✕ = 收起面板。

五、我们的共识（长按向左拉出，或点角落日期）
────────────────
「我们的共识页，与日历合并」——点月历任意一天，看这一天：
  （月历格子里会显示当天的表情心情；点月份那一行可把日历整块收起/展开）
  页面顺序：日期条（今天+表情）→ 日历 → 24小时递归圆圈 → 节律递归时间
  · 干了什么：24小时递归圆圈、节律消耗进度、自流转日程执行情况、
    当日待办完成情况、时间轴日记（共识页专属，可补记/编辑/删除）
    （当日待办的排法：还没办的排在前面、其中剩余时间最少的在最上面；
      办好的排在后面、其中最后办好的在最上面）
  · 积累了什么：每个空间的递归分钟数、可能性确定条数、新增迭代笔记

【24小时递归圆圈】整圈 = 一天24小时，灰色的圆环就是这一天的时间轴；
  每段可能性递归按持续时长画成一块扇形（颜色 = 空间颜色），
  圈里显示当日递归合计，圈下方图例按空间拆分（“学日语 4小时”）；
  进行中的那段会呼吸闪烁，红色细线 = 现在时刻。
（历史日可补记当天日记，待办按「当日X截止」口径）

六、四大板块快速上手
────────────────
【待办】（长按向上拉出）点「新建待办」记下要做的事：
  · 单次：指定日期时间（如办签证 9月21日12:00）
  · 每日：每天固定时刻（如背单词 每天21:00）
  · 每周：勾选星期几（如接妹妹放学 周一~周五20:00）
  · 备忘：无期限的随手记
  卡片会倒计时：蓝色→剩4小时变黄→剩30分钟变红（每张卡可单独调）。
  点一下变绿出现红色问号（10秒内再点一次才完成，防误触），
  再点变成灰色带绿勾=完成；点灰色卡片可恢复。
  在共识页/节律表翻到过去的某一天时，也可以点待办卡片补记
  那一天的完成情况（显示"当日15:00截止"，完成后当天生效，
  不影响今天）。

【空间】（长按向右拉出）你的兴趣像书一样独立成册。新建空间（学日语/画画/…）后：
  · 可能性确定：每天可以写很多条（情绪😊、标签、笔记、图片），
    每条还能「收藏」进一个确定性迭代里长期留存
    （一条记录最多 9 张图片；点「＋ 添加图片（可多选）」可以在相册里
      一次选中好几张，超出的会自动只收前几张并提示你）
  · 日历：按天回溯，哪天有记录一目了然
  · 确定性迭代：分类小空间（默认4个：做过的事/掌握的知识/将做的事/将要掌握的知识），像图库歌单一样收纳长期笔记
  · 待办：属于这个空间的待办

【节律表】（长按向下拉出）一天24小时的时间管理：
  · 节律递归时间：每天的时间额度，点统计卡右上角的
    「今日额度 ✎」可以为当天单独设定（30分钟~24小时），
    其他天沿用设置里的默认值
  · 可能性递归：拖空间卡到操控台投放区（或在本页点「可能性递归」）
    开始消耗额度计时，再点停止；消耗的时间会等量记到那个空间头上
  · 自流转：课程表式日程，到点自动开始用指定空间消耗额度
    （支持复制到未来几天、每周重复）
  · 时间轴日记：已搬到「我们的共识」页（长按右滑进入），随时记录想法、
    补记过去某一天

【回看历史】共识页和节律表顶部都有日期条：◀ 日期 ▶ 一天天翻，
也可以点 📅 直接打开日历选择跳到任意一天（蓝色格子=有记录的日子），
查看那天的待办完成情况、节律消耗、时间带和日记。

【每日情绪】有三种、互不影响：
  · 共识页/节律表共享的「当日心情」：日期条上的 🙂 按钮，记录这一天
    总体的情绪和标签（与各空间无关）
  · 每个空间的每日情绪：空间「可能性确定」页顶部的一排表情，
    只属于这个空间，日历上显示的就是它（不会沿用记录里的表情）
  · 每条可能性确定自己的情绪：写在记录里

【自定义背景】设置 → 背景外观：
  · 选择一张图片作为纯净首页的背景（默认是天空渐变），
    可调透明度和模糊度，看板娘与背景分开显示
  · 看板娘立绘：软件自带「系统默认的她」（mimi/ 文件夹里的图，见第八节），
    也可以在「她的空间 → 她的身体页」里换：系统默认 / 内置占位小可爱 /
    自己上传的立绘，而且能存好几套随时切换（详见第八节）
    （上传为原图不压缩，透明背景 PNG 完整保留）
  · 「设置 → 纯净首页 · 看板娘」：可调日期字号/时间字号、隐藏显示看板娘、
    一键还原看板娘的大小与位置

【动画强度】设置 → 动画强度：完整 / 轻度（默认）/ 关闭。
  除界面动效外，它同时控制养成系统的喂食动画、升级星光与爱心：
  完整 = 一次飞 4 个点心，轻度 = 3 个，关闭 = 都不出现（经验照常累积）。

【右下时间带】纯净首页右下角（手机竖屏与电脑都有）：
正在递归时显示空间名与实时计时，下方是今天24小时的
专注色带（红线=当前时刻）。想看圆圈版的图表，去「我们的共识」。

七、看板娘养成
────────────────
经验不用手动喂，全部由你的日常行为自动累积。单击看板娘 → 长按星标进入
她的空间 → 长按向上滑，就能看到「等级成长页」：
当前等级 Lv.X、称号、本级经验条、还差多少升级、下一个称号、
连续打卡天数，以及她的台词解锁进度和经验来源说明。

【经验怎么来】
  · 可能性递归：每专注 1 分钟 +1 经验
  · 完成待办：每完成一项 +20 经验
  · 可能性确定：每写一条记录 +5 经验
  · 连续打卡加成：连续打卡第 N 天，当天额外 +(N×2) 经验（最多 +20）

【连续打卡怎么算】这一天里有下面任意一件事就算打卡：
  专注过（哪怕只有1分钟）、完成过待办、写过记录；断一天就重新数。
  历史数据同样有效——等级和经验全部由已有记录实时算出，
  不用做任何数据搬家，老数据打开就有等级。

【升级与称号】
  Lv.1 时间小豆芽 → Lv.5 时间学徒 → Lv.10 时间炼金术士
  → Lv.20 时间编织者 → Lv.30 可能性空间之主
  升到 Lv.2 需要 100 经验，之后每级多 50（Lv.3 需要 150、Lv.4 需要 200……）。
  升级那一刻：屏幕提示「升级啦！Lv.X」，看板娘撒出星光 ✨ 并亲口说一句话；
  正好跨过称号档位时，还会多一条「新称号解锁」的提示。

【投喂动画】完成待办时，点心会从卡片飞向左下角的迷你看板娘，
  她「啊呜」一口吃掉，飘出 +20；写记录则在按钮上飘一个 +5。
  飞行途中左下角会短暂出现迷你看板娘（点她也能去她的空间），
  吃完约 1.4 秒自动收起，不挡正常操作。

【台词按等级解锁】Lv.1 起有 8 句，Lv.5 / Lv.10 / Lv.20 各解锁一批，
  一共 19 句；单击她时从已解锁的台词里随机挑一句，升级时优先说新解锁的。
  还差多少句解锁下一批，去「她的空间 → 等级成长页」看。

【升级时你不在场】下次打开等级成长页会补一条
  「🎉 这段时间你已经升到了 Lv.X」，只提醒一次，不会重复刷。

【动画关闭时】设置 → 动画强度选「关闭」：喂食动画、星光、爱心都不出现，
  但经验照常累积，完成待办时会用文字告诉你「看板娘 +20 经验」。

【等级会不会掉】等级是当前数据的真实镜像：撤销完成、删掉记录，
  等级会跟着回落（再完成回来就会涨回去）——不刷分，也不冤枉你。

八、她的空间（长按那颗星 0.5 秒进入）
────────────────
这是她自己的世界——她依旧站在画面正中，只是背景换成了她的夜空。
三个属于她的页面都从这里进。

【怎么进去】纯净首页单击看板娘 → 浮出那颗白圆黑星 → 按住它 0.5 秒
  → 黑星从入口处向外扩张、铺满整屏（白光一闪）→ 你就到了她的空间。
  记住了：是「长按」不是「单击」——单击只会让她跟你说句话。

【怎么出来】在她的空间里单击她 → 又浮出那颗星（这次是回程用的）
  → 按住 0.5 秒 → 同样的星光外扩 → 回到你自己的纯净首页。

【在她的空间里怎么逛】手势和首页一样（长按约 0.7 秒后滑动），
  四个方向各有各的页面：
  → 长按后向上滑：等级成长页（她的等级、称号、台词解锁进度）
  → 长按后向左滑：她的身体页（她的表情差分 / Q版 / 动作图 + 衣柜换装）
  → 长按后向右滑：她眼中的我（她看到的关于你的一切）
  → 长按后向下滑：她的日记（她写下的每一天）
  （四个页面里点左上角「返回」或直接手势返回，都回到她的空间。）

【在她的空间里双击屏幕】→ 进「对她说」跟她聊天（详见第十节）。
  另外她空间角落有个 💬 按钮，点它一样能进去。

【等级成长页】她的成长一览：当前 Lv.X、称号、本级经验条、还差多少升级、
  下一个称号、连续打卡天数；另外多两块：
  · 台词解锁进度：已解锁 X / 19 句，下一批在 Lv.5 / Lv.10 / Lv.20
  · 经验来源：专注 +1/分钟、完成待办 +20、写记录 +5、连续打卡加成

【她的身体页（v1.6 由「服装页」升级而来）】
  想让米米有表情、会变脸，就在这一页给她备图。分四段：

  ★ 现在的她：最上面一张卡，写着上面用的是哪套图、她此刻的心情。
  ★ 表情差分（5 格）：普通 / 开心 / 难过 / 生气 / 困了。
    点某一格 = 从相册选一张传上去，格子上出现小图就说明收好了；
    右上角的「×」= 清空这一格（会先问你一句）。
  ★ Q版小人（2 格）：普通 / 开心。忙碌页面右下角那个小小的她用它。
  ★ 动作图（5 格）：抱膝坐 / 睡着 / 受惊 / 扒边偷看 / 拉页面。
    她做这些动作时换上（v1.6b 的几场戏要用）。
  ★ 衣柜：以前那套（📁 系统默认的她 / 🐣 内置小可爱 / 第 N 套）。
    没传过的表情格子，会自动拿衣柜里选的那套顶上。

  ⚠️ 一张图都不传也完全能用：她会一直用系统默认的她（mimi/ 文件夹
     里的图），只是表情不跟着心情变而已。
     缺哪张就回落「普通」那张，绝不会因为缺图出问题。

  【系统默认的她（v1.6.1）】
  · 软件自带一套她的图，放在 index.html 同目录的 mimi/ 文件夹里，
    文件名是固定的：normal.png（普通）、happy.png（开心）、sad.png（难过）、
    angry.png（生气）、sleepy.png（困了）、q.png / q-happy.png（Q版）、
    sit.png / sleep.png / startle.png / peek.png / pull.png（动作图）
  · 想换她的样子 = 换同名文件（透明背景 PNG，普通 1024px 内、Q版 512px 内），
    软件一行不用改；缺哪张就自动退到 normal.png，再缺才用内置小可爱
  · 上传到手机（GitHub Pages）时，mimi/ 整个文件夹要和 index.html 一起传

  【备图要求（很重要，做对了才好看）】
  · 格式：透明背景 PNG（要抠好底，不然会带一个方块背景）
  · 尺寸：正常立绘最长边 1024px 以内；Q版 512px 以内
  · 同一套差分尽量同尺寸、同构图——只换表情，
    这样切换的时候她才不会跳一下
  · 图片原图保存不压缩，比较占地方；建议只备常用的那几张
  · 空间不够时上传会失败并提示你，删掉几张旧的再传即可

  【用 AI 生图的顺序（推荐）】
  1. 先出「正常立绘·普通」那一张，不满意就一直改描述重出，满意为止
  2. 再出「Q版·普通」（同一个角色的 Q版化）
  3. 拿满意的那张当「参考图」，只改表情词/动作词出去其余的差分
     ——这样几张才像同一个她，而不是几个不同的人
  角色的描述（发色/发型/服装/画风）定下来就别再改了；
  工具方面手机上的「即梦」两条都能满足（能传参考图 + 能出透明底），
  它出不了透明底的版本就用纯色背景出图再抠一下。

【衣柜】她可以有好几套衣服，在「她的身体」页最下面随时换：
  · 📁 系统默认的她 = 软件自带的那套（mimi/ 文件夹里的图）
  · 🐣 内置小可爱   = 软件自带的占位角色
  · 「第 N 套」     = 你自己上传的立绘，点一下 = 立刻换上
  · ＋ 上传新的一套 = 选一张（或一次多选几张）存进衣柜
                      （一次选了多张时，最后一张就是当场换上的那套）
  · 长按某套衣服 0.5 秒 = 删除它（会先问你一句，删掉就找不回来了）
  · 页面下方「一键还原大小与位置」= 把她变回默认的站姿和大小

【她眼中的我】她会把她知道的你汇报出来：连续打卡多少天、陪你专注了多久、
  你完成过多少件事、写下多少条记录、最近在忙哪个空间、今天的心情……
  下面还有几句她此刻想对你说的话（跟着你的数据变，不是固定台词）。
  这一页是只读的——她只是看着，不会替你改任何东西。
  最上面还有一张「我们之间」卡（v1.5 新增）：好感条、她怎么叫你、
  你们认识第几天，还有进「对她说」的按钮。

【她的日记】像一页纸，是她写给你的。她记着你那天专注了多久、
  办成了几件事、写了多少条记录、主攻的是哪个空间、当天的心情怎样，
  连续打卡第几天也会写进去，末尾还有一句她想对你说的话。
  · 今天这篇是活的：你补一条记录、办完一件事，它当场就变。
  · 过了午夜它就定稿，之后再翻永远是那一版——那是那一天真实的你。
  · 顶部日期条 ◀ ▶ 可以一天天往回翻，点「回到今天」一键跳回来；
    翻到过去的日子，日期下方会写「这一天已经写好了」。
  · 页面下方是「她替你记着的」：她盯着的老待办和好久没碰的空间，
    每一件都标着拖了多少天、问过没有（详见第九节）。

【她主动找你】详见第九节。

九、她主动开口（不用点她）
────────────────
以前是你点她才说话；现在她会自己找你。她说的话会以气泡出现在
立绘右上角（就是你熟悉的位置），9 秒后自己隐去，不挡任何操作。

【她什么时候会开口】
  · 每次打开软件：先跟你打个招呼（早上/下午/晚上/深夜各不相同），
    顺便说一句当天的实况——今天有几件事，最急的是哪件
  · 好几天没打开：「你终于回来了，我等了你好几天」
  · 昨天一整天什么都没做：「昨天你一天都没来，我有点担心」
  · 晚上21点后第一次回到首页：睡前总结今天专注了多久、完成了几件
  · 待办过了截止时间还没完成：「「XX」已经过点了，今晚补上？」
  · 她惦记着的事（见下）

【她惦记着的事】她会在旁边看着你：一件有期限的待办拖了两天以上还没办、
  或者一个空间五天以上没碰过，她就悄悄记下来，
  哪天主动问你一句（比如「『办签证』，你后来去了吗？」）。
  · 一件事她只问一次，问过就不再追问，不会翻来覆去地念。
  · 她记着的这些事，在她的空间 → 长按向下滑 →「她的日记」页
    下方能一次看全（拖了多少天、问过没有，都写着）。

【嫌她吵 / 想让她多说点】设置 →「她说话的频率」，一共四档：
  · 多   = 一天最多主动说 9 句
  · 正常 = 一天最多 5 句（默认，推荐）
  · 少   = 一天最多 2 句
  · 安静 = 她不再主动搭话
  ⚠️ 「安静」只关掉她主动找你说话；闹钟和额度用尽的提醒照旧——
     那两样是正事，不是闲聊。
  ⚠️ 她的「系统通知」是另一件事，在设置 →「她的通知」里有单独开关
     （详见第十节），和这里的频率互不影响。
  另外，不管哪一档，她说完一句都会安静至少 3 分钟，不会连着刷屏；
  她的主动气泡只出现在你自己的纯净首页和她的空间里（那是她说给
  你听的地方），在待办、空间这些子页面里她不会插话。

十、米米：她和你之间（v1.5 新增）
────────────────
从这一版起，看板娘有名字了——她叫「米米」。你和她之间会慢慢攒下一点东西：
她知道你是谁、记得你告诉过她的事，也会越来越敢跟你说话。

【先说清楚：她和你的关系，和等级是两回事】
  · 等级（她的空间 → 等级成长页）= 她跟着你长大的进度：你专注多久、
    完成几件事，她就长多少。那本账记的是「你做了多少」。
  · 好感（这一版新增）= 你陪了她多少。两本账分开记——
    你一天什么都没干，只是进来陪她说说话，她一样高兴。
  ⚠️ 好感**不会**因为你专注得久、完成得多而增加。那是等级的事，
     感情不该算成绩。

【好感怎么来的】（每天一共最多涨 20 点）
  · 戳她一下          +1（同一来源 30 秒内连戳不算，一天最多算 5 次）
  · 进她的空间        +2（一天一次）
  · 读她的日记        +2（一天一次）
  · 回答她的问题      +5
  · 完成她督促过的事  +3（一天最多 3 次）
  · 回应她拉出的页面  +1（一天最多 3 次；她替你拉页面是 v1.6b 的事）

【四段关系，她叫你的方式会跟着变】
  · 初识（0 点）   → 她叫你「你」，说话还有点小心
  · 熟悉（100 点） → 她叫你「你呀」，开始撒娇
  · 亲近（300 点） → 她叫你「亲爱的」，会凑过来跟你说话
  · 依恋（600 点） → 她叫你「老公」
  称呼一升级，她在**所有地方**都这么叫你了：气泡、她的日记、聊天页、
  连系统通知里也是。升级那一刻她会正式说一句、屏幕下方弹一条提示，
  她的日记里也会记下这一天。
  在哪看：她的空间 →「她眼中的我」页最上面的「我们之间」——
  好感条、她怎么叫你、你们认识第几天，都写着。

【好久不来，感情会凉一点】
  连着 7 天没打开，从第 8 天起每天 -1；但最多凉到你当前那一段的门槛
  （已经在「熟悉」的话，最多凉回 100 就停住）。回来陪陪她，很快就涨回来。
  凉一点是为了让「回来」有意义，不是要罚你。

【她的问题】她会问你一些关于你的事
  · 她会挑你安静下来的时候问（你刚操作过，她不会打断你），
    一天最多问一个，问过的不会再问第二遍。
  · 问题分三类，关系越近解锁得越多：
      关于你   （喜欢的天气、最想去的远方、一天里最喜欢的时刻…）— 一开始就会问
      关于你们 （在你眼里我是什么样的人、你喜欢我哪一点…）      —「熟悉」以后
      关于她   （她喜欢星星、她怕不怕黑、她的生日想定在哪天…）  —「亲近」以后
  · 弹出来的是一张选择题卡片，从选项里挑一个就行。你说的话她会一直记着，
    过几天还会拿它来接你的话（比如「你跟我说过你最喜欢下雨天，
    今天正好是呢」）；她的日记里也会写一笔「今天你告诉我……」。
  · 不想答就点「等下再聊」，她不会追问。

【对她说】你可以直接跟她聊天
  · 怎么进：她的空间里**双击屏幕**（先闪一页加载过渡再进去），
    或者点她空间角落的 💬 按钮，也可以从「我们之间」那张卡进。
  · 你说一句，她答一句，聊过的话都留在页面上。她认得出这些话题：
    早安、晚安、想你、喜欢你、夸她、道歉、生气、难过、无聊、谢谢、
    问她是谁、叫她米米、吃饭、加油、星星、找她帮忙、打招呼……
  · 认不出来的句子，她会老实说没听懂，然后把它悄悄收进「小本子」
    （聊天页底部会写收了多少句）——以后给她接上真正的对话能力时，
    这些就是她学着懂你的底子。
  · 不想打字就点下面的快捷 chips（早安 / 晚安 / 想你…），照样能接话。
  · 全是你手机里算的，不联网、不上传。

【她的通知】她走出软件来找你
  · 这是这一版唯一需要「多传一个文件」的功能：把 index.html 和同目录的
    新文件 sw.js 一起部署到网上（GitHub Pages 等），手机用浏览器打开后
    「添加到主屏幕」，再从主屏幕图标进去（详见第一节的开头）。
  · 认识两天之后，她会自己来问你：「可以让我以后在外面也能提醒你吗？」
    你点了同意，才会弹出系统的通知授权框；点「先不用」她就不问了，
    也不会再拿这事打扰你。
  · 开了之后：你把软件切到后台或锁屏，她说的话就会以系统通知送到你手上
    ——抬头是她的名字，像有人给你发消息。你正看着软件的时候她不发通知
    （页面上有气泡就够了）。
  · 想关掉：设置 →「她的通知」→ 关掉她的通知（那里也有「试试发一条」，能立刻验证）。
  · ⚠️ 下面这几种情况收不到，都是浏览器的限制，不是她的问题：
      - 电脑上直接双击 index.html 打开（本地文件没有通知权限）
      - 只是当普通网页开着，没有「添加到主屏幕」
      - iPhone 需要 iOS 16.4 或更新版本
      - 软件被彻底关掉了——她只在软件还活着的时候送得出来

十一、她会动了（v1.6 新增）
────────────────
这一版起，米米不只是站在那儿了——她有自己的心情、自己的小动作，
你怎么对她，她怎么应你。

【她有心情了】
  她头顶会冒出一个小小的圆脸：😊 开心 / 🥺 担心 / 😢 难过 / 😤 生气 /
  😴 困了 / 😳 害羞。心情不是随便变的，都有原因：
  · 你办完一件事 → 她开心
  · 待办快过期、变成红色 → 她有点担心
  · 你连着戳她 5 下 → 她真的会生气（😤）
  · 深夜（23 点后）→ 她困了，说话做事都轻下来
  · 你把她捏大 / 拖到新地方 → 她会害羞 / 委屈
  一件事惹出来的心情大约保持一分半，之后她自己淡回平静。
  ⚠️ 心情只是她的表情，不影响任何功能，也不催你。

【她在「她的身体」页有图的时候，脸会跟着心情换】
  没传过图也没关系：头顶的小圆脸不依赖任何图片，一样看得见她的心情。

【她会自己做点小动作】（只有你在的地方：纯净首页 / 她的空间）
  · 你安静一分钟以上：她会蹦一下、扭一扭，偶尔顺口说一句
  · 你安静很久（四分钟以上）：她会抱膝坐下、打个瞌睡、没精打采地塌着
  · 你一碰屏幕，她立刻把动作收起来看着你——不会自顾自演下去
  ⚠️ 设置 →「动画强度」三档管着她：
     完整 = 所有动作都播 / 轻度（默认）= 只播蹦跳这类轻动作 /
     关闭 = 一个都不播（心情和表情照旧，只是不动）

【你怎么对她，她怎么应你】（这些响应不受「一天说几句话」的限制——
  你理她，她随时都该答得上）
  · 连戳 5 下（1.5 秒内）：她会「呀！别戳啦」，吓一跳、生气
  · 把她拖到角落：她会问一句「要把我放这里吗？」（只问第一次）
  · 双指捏到 1.5 倍以上：她害羞（「原来你想看大一点的我呀」）
  · 捏到 0.6 倍（最小）：她有点委屈（「你还看得见我吗」）
  · 只是轻轻调大小、挪一点点位置：她什么都不会说——那是正常操作
  · 摇一摇手机（安卓）：摇两下她说头晕，摇五下她真的生气
    ⚠️ iPhone 上「摇一摇」要先允许一次（系统规定必须由你的手点一下
      才能开），到时会由她开口问你，点一下那句话就开好了。
       电脑上直接双击打开的话，摇一摇直接静默关掉，不报错。

【震动】安卓上她生气/兴奋时会震一下；iPhone 的网页做不到震动
  （苹果的限制），所以改成整屏轻轻闪一下——一样是「被戳到了」的感觉。

【忙碌页面右下角的她】在待办、空间、节律表、设置这些「干活的地方」，
  右下角会站着一个小小的 Q版米米陪着你。她不挡任何按钮，只是陪着。
  （她自己的页面里不会重复出现——那儿本来就是她的地方。）

· 她的空间     = 看板娘自己的世界（长按白圆黑星 0.5 秒进入），
                 里面有她的等级成长页、她的身体页、她眼中的我

                 没传过的表情格子会自动用衣柜里选的那套顶上
· 她的日记     = 她写给你的每天一页：那天做了什么、心情怎样；
                 今天这篇是活的（跟着数据变），过了午夜就定稿冻结

                 好感记「你陪了她多少」

                 认识第几天

                 你的回答她会一直记着，过几天还会拿来接你的话
· 对她说       = 她的空间里双击屏幕进的聊天页，你说一句她答一句
· 她的通知     = 你把软件切到后台后，她说的话以系统通知送到你手机上
                 （需要部署 sw.js + 添加到主屏幕，详见第十节）

十三、常见问题
────────────────
· 时间怎么算的？
  递归计时按真实时间走：开始递归后就算关掉页面，时间也照算
  （关超过2小时会自动结束，防止忘记停止）。
  自流转日程即使关着页面也会按课程表补算。

· 存储满了怎么办？
  软件使用浏览器的大容量存储（通常几百MB，设置页会显示可用容量），
  图片还会自动压缩（最长边1000像素），正常使用很难存满。
  万一提示空间不足，导出备份后删除一些旧图片即可。
  个别旧浏览器会退回兼容模式（约5MB），建议用最新版浏览器打开。

· 更新后第一次打开：数据会自动从旧的小仓库搬进新的大仓库（几秒钟完成），
  之后请一直用新版页面；旧版页面看不到新仓库里的数据。

· 误删了怎么办？
  空间删除其实是「归档」，历史数据都保留，导出备份里也有。
  但「她的衣柜」里长按删掉的衣服是直接抹掉、不留存档的，
  删之前会先跟你确认一次；想留的话提前把原图另存一份。

· 我在设置里隐藏了看板娘，为什么她的空间里她还在？
  那是她的地盘——隐藏只对你的纯净首页生效，她自己的空间里她一定在场。

· 她怎么老跟我说话？
  设置 →「她说话的频率」里挑「少」或者「安静」就行。
  选「安静」之后，她只会为了闹钟和额度用尽才开口。

· 她说的话是怎么来的？会联网吗？
  全是你手机里算出来的：她看你的数据（专注了多久、办了几件事、
  几天没来了……），再按不同的场合挑一句合适的话说给你听。
  整个软件不联网、不上传任何内容，这一点不会变。
  以后版本会给她接上真正的对话能力，那时她会更懂你。

· 她的日记能改吗？
  今天的这篇一直跟着你的数据走——你补一条记录、完成一件事，它当场就变；
  过了午夜就定稿，之后再翻永远是那一版。她的日记是只读的，
  你不满意也改不动它（她说了算），但你今天做了什么，可以现在就去做。

· 她怎么老是自己动来动去？（v1.6）
  设置 →「动画强度」→ 选「关闭」她就安静站着不动了，
  心情圆脸和表情差分照旧（只是不再蹦蹦跳跳）。
  选「轻度」则只留蹦一下、扭一扭这类小动作。

· 我不传图，她会变成什么样？（v1.6）
  和以前完全一样——一直用「她的身体」页衣柜里选的那套
  （或系统默认的她 mimi/ 文件夹 / 内置小可爱）。
  传了表情差分她才开始变脸，不传就一直是同一张，功能一点不受影响。

· 换手机后她自己动的那些图还在吗？
  在。表情差分和衣柜一样，都在「导出备份」里（含图片本体），
  新手机导入备份就回来了。

· 我一天什么都没干，好感会掉吗？
  不会。好感只在两件事上掉：连着 7 天以上没打开软件（第 8 天起每天 -1，
  而且最多凉到你当前那一段的门槛）。你只要进来说句话、戳戳她，就涨回来了。
  另外，专注得久、完成得多**不会**让好感涨——那是等级的事。

· 她问我的问题，我不想答怎么办？
  点「等下再聊」就行，她不会追问；过几天你安静下来的时候她还会再问一次。
  问过并且你答过的，她不会再问第二遍。

· 我跟她说话，她怎么回我「没听懂」？
  她现在的对话能力是本地的关键词规则（不联网），只认得出常见的话题。
  没听懂的句子她会收进小本子——以后给她接上真正的对话能力时，
  这些就是她学着懂你的底子。点下面的快捷 chips（早安 / 晚安 / 想你）
  她一定接得上。

· 为什么她收不到通知 / 我手机没响？
  依次检查：①软件是部署在网上、并且「添加到主屏幕」后从图标进的；
  ②iPhone 要 iOS 16.4 以上；③设置 →「她的通知」里是「已开启」，
  可以点「试试发一条」；④她只在软件还活着（前台或后台）的时候送得出来，
  彻底关掉就没有了。电脑上双击 index.html 打开是用不了通知的，
  这是浏览器的限制。

· 长按那颗星没反应？
  要按住 0.5 秒不动（约半秒），中途松手或手指移开都会取消；
  星标浮出后 6 秒会自己隐去，再点一下她就重新出现了。

· 想先体验一下？
  打开后双击屏幕 → 面板右上 ⚙ 设置 →「生成示例数据」，
  会创建学日语、练画画、软件开发三个空间和几条示例待办，随便点不心疼；
  体验完可在设置里「清空全部数据」（会先帮你自动下载备份）。
