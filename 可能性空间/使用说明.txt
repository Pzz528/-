一、怎么打开使用
────────────────
· 电脑：双击「index.html」文件，用 Chrome 或 Edge 打开即可。
· 安卓手机：把 index.html 传到手机（微信/QQ/USB 都行），
  用 Chrome 打开。
· iPhone：建议请开发者把本文件免费部署到网上（如 GitHub Pages），
  然后用 Safari 打开网址，点「分享 → 添加到主屏幕」，
  之后就能像普通 App 一样点图标进入，
  主屏幕会显示你自定义的App图标（不再是默认的"可"字）。

二、⚠️ 最重要的事：数据备份（请先读这条）
────────────────
你的所有数据（空间/待办/日记/图片）都存在「当前浏览器的本地存储」里，
不会上传到任何服务器。这意味着：

  1. 换浏览器 = 数据不在了（需要在旧浏览器导出、新浏览器导入）
  2. 清除浏览器数据 = 数据不在了
  3. 换电脑 = 数据不在了

所以请养成习惯：每周点一次「设置 → 导出备份」，
把下载的 JSON 文件保存好（可以存到网盘）。
万一数据丢失，在「设置 → 导入备份」选那个文件就能完整恢复（含图片）。

三、四大板块快速上手
────────────────
【首页】五个独立板块：
  · 日期时间：今天的日期和实时时钟
  · 日历：月历一览（有记录的日子显示标记），点任意日期
    跳到那天，下方各板块跟着切换
  · 今日待办：收纳卡（点一下摊开全部待办，任务列表式）
  · 节律：当天额度消耗进度与正在进行的递归
  · 可能性空间：你的兴趣空间入口

【待办】点「新建待办」记下要做的事：
  · 单次：指定日期时间（如办签证 9月21日12:00）
  · 每日：每天固定时刻（如背单词 每天21:00）
  · 每周：勾选星期几（如接妹妹放学 周一~周五20:00）
  · 备忘：无期限的随手记
  卡片会倒计时：蓝色→剩4小时变黄→剩30分钟变红（每张卡可单独调）。
  点一下变绿出现红色问号（10秒内再点一次才完成，防误触），
  再点变成灰色带绿勾=完成；点灰色卡片可恢复。
  在首页/节律表翻到过去的某一天时，也可以点待办卡片补记
  那一天的完成情况（显示"当日15:00截止"，完成后当天生效，
  不影响今天）。当天待办全部完成时，首页收纳卡会变成浅绿色。

【空间】你的兴趣像书一样独立成册。新建空间（学日语/画画/…）后：
  · 可能性确定：每天可以写很多条（情绪😊、标签、笔记、图片），
    每条还能「收藏」进一个确定性迭代里长期留存
  · 日历：按天回溯，哪天有记录一目了然
  · 确定性迭代：分类小空间（默认4个：做过的事/掌握的知识/将做的事/将要掌握的知识），像图库歌单一样收纳长期笔记
  · 待办：属于这个空间的待办

【节律表】一天24小时的时间管理：
  · 节律递归时间：每天的时间额度，点统计卡右上角的
    「今日额度 ✎」可以为当天单独设定（30分钟~24小时），
    其他天沿用设置里的默认值
  · 可能性递归：在空间卡片点「可能性递归」开始消耗额度计时，再点停止；
    消耗的时间会等量记到那个空间头上
  · 自流转：课程表式日程，到点自动开始用指定空间消耗额度
    （支持复制到未来几天、每周重复）
  · 时间轴日记：随时「记录想法」，也可以回到过去的某一天补记

【回看历史】首页和节律表顶部都有日期条：◀ 日期 ▶ 一天天翻，
也可以点 📅 直接打开日历选择跳到任意一天（蓝色格子=有记录的日子），
查看那天的待办完成情况、节律消耗、时间带和日记。

【自定义背景】设置 → 背景外观：
  · 选择一张图片作为软件背景（默认是白色），可调透明度和模糊度
  · 设置背景后，在首页双指收缩，图片会浮上来覆盖整个屏幕，
    边缘小字显示日期、时间、最优先待办和正在递归的空间；
    双指放大或左上角「✕ 退出覆盖」恢复为背景
  · 首页左上角也有 🖼 按钮可进入覆盖模式
  · 未设置背景图片时，此功能不会出现

【每日情绪】有三种、互不影响：
  · 首页/节律表共享的「当日心情」：日期条上的 🙂 按钮，记录这一天
    总体的情绪和标签（与各空间无关）
  · 每个空间的每日情绪：空间「可能性确定」页顶部的一排表情，
    只属于这个空间，日历上显示的就是它（不会沿用记录里的表情）
  · 每条可能性确定自己的情绪：写在记录里

四、小词典
────────────────
· 可能性空间   = 你的一个兴趣（学日语、拍视频……）
· 可能性确定   = 在空间里做记录（情绪/标签/笔记/图片）
· 可能性递归   = 用空间消耗节律递归时间（专注计时）
· 节律递归时间 = 每天的时间额度（被递归消耗）
· 可能性递归时间 = 已消耗的时间（等量记到空间名下）
· 确定性迭代   = 空间内的分类小空间（收纳长期笔记）
· 自流转       = 课程表式自动递归

五、常见问题
────────────────
· 时间怎么算的？
  递归计时按真实时间走：开始递归后就算关掉页面，时间也照算
  （关超过2小时会自动结束，防止忘记停止）。
  自流转日程即使关着页面也会按课程表补算。

· 存储满了怎么办？
  软件使用浏览器的大容量存储（通常几百MB，设置页会显示可用容量），
  图片还会自动压缩（最长边1000像素），正常使用很难存满。
  万一提示空间不足，导出备份后删除一些旧图片即可。
  个别旧浏览器会退回兼容模式（约5MB），建议用最新版浏览器打开。

· 更新后第一次打开：数据会自动从旧的小仓库搬进新的大仓库（几秒钟完成），
  之后请一直用新版页面；旧版页面看不到新仓库里的数据。

· 误删了怎么办？
  空间删除其实是「归档」，历史数据都保留，导出备份里也有。

· 想先体验一下？
  打开后点右上角齿轮 →「生成示例数据」，会创建学日语、练画画、
  软件开发三个空间和几条示例待办，随便点不心疼；
  体验完可在设置里「清空全部数据」（会先帮你自动下载备份）。
